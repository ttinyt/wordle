# Wordle clone in react

This is my first project to learn react!
I love playing wordle, so thought I would make my own take on it.
This is still a work in progress, but enjoy ⸜(｡˃ ᵕ ˂ )⸝★

All credits of course to the official (wordle)[https://www.nytimes.com/games/wordle/index.html].
First part of implementation of my wordle is following the tutorial of netninja on (youtube)[https://youtube.com/playlist?list=PL4cUxeGkcC9gXdVXVJBmHpSI7zCEcjLUX&si=rta5zK6T7_ZX2NCS].
After that I found a blog post from (cupofcode)[https://cupofcode.blog/wordle-in-react-part-1/] on how to make it look more similar to the real wordle, and I took heavy inspiration for some parts here as well.
Other than this I chose to code with no AI other than to find defects.



## How to play
Download the whole project, then:
go to project directory in the terminal

In the project directory, you can run:
`npm start`
Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
